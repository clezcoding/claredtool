# Clared – Globale VAT-/USt-Decision-Matrix

Dieses Dokument beschreibt eine globale, AI-freundliche Decision-Matrix für die Steuer-Engine von **Clared**. Jede Zeile repräsentiert einen Transaktions-Archetyp (Supplier-Land/Region, Customer-Land/Region, B2B/B2C, Leistungsart) und führt deterministisch zu einer steuerlichen Entscheidung (Ort der Leistung, Steuerschuldner, Steuersatz auf der Rechnung, Reverse-Charge-Status, Rechtsreferenzen, Textbausteine).

Die Matrix ist bewusst generisch gehalten, um sich auf „Regelklassen“ zu konzentrieren und nicht auf jede einzelne Kombination einzelner Staaten. Innerhalb einer Regelklasse werden einzelne Länder später über spezifische Rule-Module (EU-Mitgliedstaaten, UAE, etc.) verfeinert.

## Spalten-Definition

| Spalte                  | Beschreibung |
|-------------------------|-------------|
| id                      | Eindeutige Kennung der Regel (Archetyp). |
| supplier_region         | Region/Land des leistenden Unternehmers (z.B. "EU", "EU:AT", "US", "UAE"). |
| customer_region         | Region/Land des Leistungsempfängers. |
| supplier_is_business    | Bool, ob der Lieferant Unternehmer ist. |
| customer_is_business    | Bool, ob der Kunde Unternehmer ist (B2B) oder Privatperson (B2C). |
| supplier_vat_registered | Bool, ob der Lieferant in seiner Jurisdiktion für VAT/USt registriert ist. |
| customer_vat_registered | Bool, ob der Kunde VAT/USt-registriert ist (UID/TRN o.ä.). |
| supply_type             | Typ der Leistung (service, digital_service, goods, property, special). |
| place_of_supply_region  | Resultierende Jurisdiktion für Ort der Leistung. |
| tax_liability_party     | "supplier" oder "customer" (Reverse Charge). |
| invoice_tax_rate        | Steuersatz auf der Rechnung (numerisch, z.B. 0, 20, 5). |
| invoice_tax_shown       | Bool, ob Steuer auf der Rechnung ausgewiesen wird. |
| reverse_charge_flag     | Bool, ob Reverse-Charge (Umkehr der Steuerschuld) gilt. |
| legal_reference         | Text/IDs für Rechtsnormen (z.B. EU VAT Directive Artikel, nationales Gesetz, UAE VAT Public Clarification). |
| invoice_text_block_id   | ID des Textbausteins, der auf der Rechnung verwendet wird. |
