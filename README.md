# Clared

Paid SaaS desktop app for global B2B invoicing with a live tax engine. Not open source. Not free.

- **Client:** Tauri (macOS + Windows)
- **Backend:** NestJS on the vendor Coolify cluster (Postgres, Redis, Authentik)
- **License:** `UNLICENSED` — see `LICENSE`

Local Docker-compatible services run in OrbStack. Production is the founder's Coolify.
