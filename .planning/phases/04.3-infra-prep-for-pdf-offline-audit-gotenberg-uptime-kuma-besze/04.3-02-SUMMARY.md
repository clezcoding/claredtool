## Decisions Made

- Redis for BullMQ is `connection: { url }` + `prefix: "clared-bull"` (Context7 QueueOptions). Session KV stays on `RedisService`.
- Processor lives only on `WorkerModule` so the HTTP process does not consume jobs.
- Local dummy Basic Auth is `dev`/`dev`, matching `.env.example`. Compose defaults `${…:-dev}`.
- Engine is **OrbStack** (`docker context` `orbstack`). Gotenberg has no public hostname and no OTEL.
- Test env: `lazyConnect` so existing e2e `AppModule` boots without a live Bull Redis (analog `MemoryStore`).
