## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Internet → Gotenberg | WAN must not reach PDF converter | None (no public FQDN) |
| Worker → Gotenberg | Internal Docker network + Basic Auth | HTML invoice stub → PDF bytes |
| Nest API → Redis | BullMQ job payloads | Job id + html string (no tokens) |
| Nest → stdout / OTLP | Logs and spans | Operational metadata only (PII redacted) |
| Local process → collector | Dev/test without collector | No hang when exporters=none |
| WebView JS → fs/sql | Desktop offline prep | APPDATA/TEMP paths; SQLCipher key stays in Rust |
| Rust → keychain | SQLCipher secret | 32-byte key never crosses to JS |
| Public internet → Kuma/Beszel/Grafana | Monitor/obs UIs | Built-in login only (no Authentik) |
| Coolify cron → Healthchecks.io | Dead-man ping | Ping URL secret in Coolify env |
| Human browser → ops UIs | First-admin setup | Passwords in password manager, not git |
