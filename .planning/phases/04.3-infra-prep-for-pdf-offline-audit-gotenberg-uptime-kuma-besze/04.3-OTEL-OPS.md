## Collector config (D-30)

OTLP HTTP `0.0.0.0:4318`. Logs exporter **otlphttp** to Loki native OTLP — not `lokiexporter`, not Promtail/Alloy. Deprecation warning `"otlphttp" alias is deprecated; use "otlp_http"` is expected; keep `otlphttp` for D-30.

```yaml
receivers:
  otlp:
    protocols:
      http:
        endpoint: 0.0.0.0:4318
processors:
  batch: {}
exporters:
  otlphttp/logs:
    endpoint: http://loki:3100/otlp
    tls:
      insecure: true
  otlp/tempo:
    endpoint: tempo:4317
    tls:
      insecure: true
  prometheus:
    endpoint: 0.0.0.0:8889
extensions:
  health_check:
    endpoint: 0.0.0.0:13133
service:
  extensions: [health_check]
  pipelines:
    traces:
      receivers: [otlp]
      processors: [batch]
      exporters: [otlp/tempo]
    logs:
      receivers: [otlp]
      processors: [batch]
      exporters: [otlphttp/logs]
    metrics:
      receivers: [otlp]
      processors: [batch]
      exporters: [prometheus]
```

Loki also has `allow_structured_metadata: true` (required for OTLP ingest).
