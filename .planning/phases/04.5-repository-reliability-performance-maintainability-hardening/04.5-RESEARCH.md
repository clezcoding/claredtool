## Common Pitfalls

### Pitfall 1: Schema SSOT drift

**What goes wrong:** Edit `packages/tax-engine/src/schema/...` but not `docs/clared-tax-rule-dsl-schema.json`.

**Why it happens:** Two copies; build copies to `dist/schema/`.

**How to avoid:** Edit `docs/` first; `cmp` or CI check identity; tax-engine build copies to dist.

**Warning signs:** Backend/desktop validation diverges from engine tests.

### Pitfall 2: Updater split increases gzip >5%

**What goes wrong:** Thin-wrapper refactor duplicates shared code across chunks.

**Why it happens:** Static+dynamic import graph for `updater.ts`.

**How to avoid:** Measure total gzip before/after; reject if >+5% (D-07).

**Warning signs:** `INEFFECTIVE_DYNAMIC_IMPORT` warning persists after refactor.

### Pitfall 3: Deploy script changes secret surface

**What goes wrong:** Token logged or new env vars required in Coolify.

**Why it happens:** Accidental `set -x` or new curl headers in script.

**How to avoid:** Same env vars as today; ShellCheck SC2155/SC2034; no `echo` of secrets.

**Warning signs:** `$GITHUB_STEP_SUMMARY` contains tokens.

### Pitfall 4: Docs rewrite breaks GSD history

**What goes wrong:** Editing immutable `04.4-*-SUMMARY.md` / `PLAN.md` bodies.

**Why it happens:** Correcting `backend-test` references in-place.

**How to avoid:** Add `04.4-POST-MERGE-ADDENDUM.md` or section in `04.5-VALIDATION.md` (D-16).

**Warning signs:** Git diff touches completed plan execution logs.

### Pitfall 5: CI optimization weakens gates

**What goes wrong:** Skip Trivy, clippy, or CodeQL paths to save minutes.

**Why it happens:** Aggressive path filters.

**How to avoid:** Only parallelize independent steps; keep scanners; document runner minutes delta.

**Warning signs:** Fewer workflow steps after "optimization" PR.
