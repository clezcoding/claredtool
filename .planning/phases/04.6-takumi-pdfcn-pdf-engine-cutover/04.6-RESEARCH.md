## Summary

Phase 4.6 is a **one-way engine cutover**, not a dual-run. Nest API renders invoice PDF bytes in-process from InvoiceModel + TaxDecision via `takumi-pdf` `render()` and pdfcn **Invoice Minimal** (shadcn copy-paste, then Crafted tokens). Gotenberg, Chromium HTML convert, BullMQ `pdf-generation`, and `clared-worker` are deleted in the same PR/wave as the new renderer. Redis stays for session KV. Phase 4.7 owns Factur-X XML + PDF/A-3b; Phase 5 owns download/view.

`takumi-pdf` is WASM, Node `>=20.19`, React 18/19 peer. It ships a **CJS** `node.require` entry (`bundlers/node.cjs`), so Nest `commonjs` `require()` works without webpack. Do **not** esbuild-flatten the API. Keep `node_modules/takumi-pdf/pkg/takumi_pdf_wasm_bg.wasm` in the image. Current registry version this session: **0.14.2** (prior research noted 0.14.1 — pin at execute). pdfcn is **not** an npm runtime: `npx shadcn@latest add @pdfcn/takumi/invoice-minimal`. Do not install npm `takumi`, `pdfcn`, `forme`, or `@takumi-rs/core`.

Nyquist is ON. Existing backend Jest is the framework. Wave 0 must **replace** Gotenberg/queue specs that would otherwise stay GREEN while the engine is wrong, and add fixture `render()` tests plus decommission greps. `/health/ready` must keep working for Coolify deploy polls **without** a Gotenberg key (D-25).

**Primary recommendation:** Cut over in one execute wave: `@clared/pdf-templates` + sync `InvoicePdfService` + three `%PDF-` fixtures, then delete Gotenberg/worker/queue/GHA worker half. Engine proof is fixtures, not Ready. Do not reopen Gotenberg vs Takumi.

### Pattern 1: Sync in-process render

**What:** Nest service calls `renderInvoice(...)` and returns `PdfBytes`. No queue.
**When to use:** Always in 4.6 (D-02).
**Example:**

```ts
// Source: https://takumi.kane.tw/docs/pdf + fonts-and-images (local bytes)
import { readFile } from "node:fs/promises";
import { PdfRenderer } from "takumi-pdf";
import { PageNumber, TotalPages } from "takumi-pdf/primitives";

const renderer = new PdfRenderer();
const inter = await readFile(new URL("../fonts/Inter.woff2", import.meta.url));

export async function renderInvoice(node: React.ReactNode): Promise<Uint8Array> {
  return renderer.render(node, {
    size: "a4",
    fonts: [{ name: "Inter", data: inter }],
    footer: (
      <div tw="flex w-full justify-center text-[10px] text-gray-500">
        Page <PageNumber /> of <TotalPages />
      </div>
    ),
  });
}
```

Nest is CJS: if `import.meta.url` is awkward, use `path.join(__dirname, "../fonts/Inter.woff2")` after `tsc` emit. Official offline pattern uses `import.meta.url` on the ESM docs page [CITED: https://takumi.kane.tw/docs/typography-and-fonts#fonts-in-ci-and-offline-renders].

## Common Pitfalls

### Pitfall 1: Wrong npm names
**What goes wrong:** `takumi` CLI or empty `pdfcn` installed; render never works.
**Why:** Names collide with the product words.
**How to avoid:** D-08 deny-list + post-`shadcn add` `package.json` grep.
**Warning signs:** `require("takumi")` or `"pdfcn": "0.0.0"` in lockfile.

### Pitfall 2: Nest `commonjs` + no `jsx`
**What goes wrong:** `tsx` in `apps/backend/src` fails typecheck.
**Why:** `apps/backend/tsconfig.json` has `"module": "commonjs"` and no `jsx` [VERIFIED: apps/backend/tsconfig.json:3-21].
**How to avoid:** `@clared/pdf-templates` with `jsx: react-jsx`.
**Warning signs:** `TS17004` / cannot find module `react/jsx-runtime`.

### Pitfall 3: WASM missing in image
**What goes wrong:** Runtime `ENOENT` `takumi_pdf_wasm_bg.wasm`.
**Why:** esbuild flatten, or Docker COPY omitting `node_modules/takumi-pdf/pkg`. Nest `tsc` does **not** copy wasm into `dist/`.
**How to avoid:** Leave package in `node_modules`; do not bundle. Wave 0: `render()` inside the API image (discretion).
**Warning signs:** Works on laptop `pnpm start`, dies in Coolify.

### Pitfall 4: `googleFonts()` in prod
**What goes wrong:** Render hangs/fails without Google; extra egress.
**Why:** Official samples default to `googleFonts(["Inter"])`.
**How to avoid:** `readFile` WOFF2 → `{ name, data }`. Grep `googleFonts` in pdf-templates = 0 in prod path.
**Warning signs:** Coolify logs `TypeError: fetch failed`.

### Pitfall 5: Old specs stay GREEN
**What goes wrong:** `pdf.contract.spec.ts` still asserts `PDF_QUEUE === "pdf-generation"` after the engine cutover if someone only adds new files.
**Why:** Nyquist sampling of **old** tests does not prove the new renderer.
**How to avoid:** Wave 0 **rewrites/deletes** Gotenberg specs; new fixture tests are the gate.
**Warning signs:** CI green with `gotenberg.client.ts` still present.

### Pitfall 6: Deploy script still pins worker
**What goes wrong:** GHA deploy fails or recreates `clared-worker`.
**Why:** `coolify-deploy-nest.sh` + mock tests encode 04.5 API→worker order.
**How to avoid:** API-only script; rewrite `coolify-deploy-nest.test.sh`; drop `WORKER_UUID` / `COOLIFY_APP_WORKER`.
**Warning signs:** workflow still has `push-worker`.

### Pitfall 7: CSS subset / blur
**What goes wrong:** Copied pdfcn uses `filter: blur` → render throws.
**Why:** PDF has no blur operator [CITED: troubleshooting].
**How to avoid:** Flat Crafted layout: flex, stacks, tables, `break-inside-avoid` on line rows.
**Warning signs:** `A PDF cannot draw filter: blur`.

### Pitfall 8: `/health/ready` still keys `gotenberg`
**What goes wrong:** Deploy poll 503 when `GOTENBERG_URL` deleted, or false-green `skipped (GOTENBERG_URL unset)`.
**Why:** Indicator at health.controller.ts:60-75 [VERIFIED].
**How to avoid:** Delete the indicator entirely (D-25). E2E asserts body has postgres+redis and **not** `gotenberg`.
**Warning signs:** JSON still contains `"gotenberg"`.

### Pitfall 9: PII in throw messages
**What goes wrong:** Invoice lines/names in Nest exceptions / Pino.
**Why:** D-26 / 04.3 D-23.
**How to avoid:** Generic `Render fehlgeschlagen` (German log names); never interpolate seller/line text.
**Warning signs:** Test fixture names appearing in `err.message`.

### Pitfall 10: shadcn add pulls Forme
**What goes wrong:** `@pdfcn/forme/invoice-minimal` or `@formepdf/react`.
**Why:** Docs show both namespaces side by side.
**How to avoid:** Only `@pdfcn/takumi/invoice-minimal`. Grep `forme` / `@formepdf`.
**Warning signs:** New dep `@formepdf/react`.
