## Warnings

### WR-01: JS `scrubSentryEvent` only drops `Authorization`, does not redact other request headers

**File:** `apps/desktop/src/lib/sentry.ts:71-84`  
**Issue:** `scrubSentryEvent` deletes the `Authorization` header but leaves all other header values verbatim. Rust `sentry_scrub_request` redacts every header value and strips sensitive `env` entries. Browser events that include `Cookie`, `X-Auth-Token`, or similar headers in `event.request` can still ship token-bearing values through the JS `beforeSend` path even though D-40 scrubbing is otherwise in place.

**Fix:**
```typescript
if (headers) {
  for (const key of Object.keys(headers)) {
    if (key.toLowerCase() === "authorization") {
      delete headers[key];
      continue;
    }
    headers[key] = redactString(headers[key], key);
  }
}
```
Add a test asserting a non-Authorization header with a token-like value is redacted.

### WR-02: JS `scrubSentryEvent` omits `tags`; Rust scrubber redacts them

**File:** `apps/desktop/src/lib/sentry.ts:69-105`, `apps/desktop/src-tauri/src/lib.rs:389-396`  
**Issue:** Rust `sentry_scrub_event` redacts all tag values via `sentry_redact_string`. JS `scrubSentryEvent` never touches `tags`. Any future or third-party `Sentry.setTag` / `captureException` call that puts customer names, emails, or tokens into tags bypasses the JS scrub pipeline.

**Fix:**
```typescript
if (scrubbed.tags) {
  scrubbed.tags = Object.fromEntries(
    Object.entries(scrubbed.tags).map(([key, value]) => [
      key,
      typeof value === "string" ? redactString(value, key) : value,
    ]),
  );
}
```
Extend `SentryEvent` type and add a tags regression test.

### IN-01: `tauri dev` checks production FaynoSync endpoint

**File:** `apps/desktop/src-tauri/tauri.conf.json:56-58`  
**Issue:** Source `tauri.conf.json` (used by `pnpm tauri dev`) points at the production `updates.puzzlessdev.online` endpoint. CI/release builds patch to staging or production via `patch-tauri-config.mjs`, but local dev runs can hit the production update channel unintentionally.

**Fix:** Point dev `endpoints` at staging, or document that devs must set `TAURI_UPDATER_ENDPOINT` before `tauri dev` when testing updater flows.
