### `apps/desktop/src/lib/link-guard.ts` (utility / middleware, event-driven)

**Analog:** Rust `allow_navigation` + `clared://` handling in `lib.rs` (do not break OIDC)

**Scheme allowlist** (`lib.rs` lines 104–114):
```rust
fn allow_navigation(url: &Url, backend: Option<&str>, authentik: Option<&str>) -> bool {
    match url.scheme() {
        "about" => true,
        "data" => url.as_str() == login_init_url().as_str(),
        "http" | "https" => {
            let origin = origin_key(url);
            origin.as_deref() == backend || origin.as_deref() == authentik
        }
        _ => false,
    }
}
```

**Deep-link `clared://` preserve** (`lib.rs` lines 159–176):
```rust
.on_navigation(move |url| {
    if url.scheme() == "clared" {
        // ticket extract + close login — keep intact
        return false;
    }
    allow_navigation(url, backend_origin.as_deref(), authentik_origin.as_deref())
})
```

**Frontend deep-link parse** (`session-provider.tsx` lines 50–61):
```typescript
function ticketFromUrls(urls: string[] | null | undefined): string | undefined {
  for (const raw of urls ?? []) {
    try {
      const url = new URL(raw);
      if (url.protocol === "clared:") {
        const ticket = url.searchParams.get("ticket");
        if (ticket) return ticket;
      }
    } catch {
      /* ignore malformed deep links */
    }
  }
}
```

**Policy (D-34):** `https:` → `opener`; `http:` localhost/dev only; `clared:` in-app (no opener); `file:`/unknown → block + log. Main WebView only — login window keep Rust allowlist.
