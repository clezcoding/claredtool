## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing |
| md | 16px | Default element spacing |
| lg | 24px | Section padding, card spacing |
| xl | 32px | Layout gaps, sidebar padding |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing, empty state |

Exceptions: Touch targets for interactive controls follow 44px minimum (not strictly 4-multiple) per platform accessibility guidelines.

**Source:** Default 8-point scale. Aligns with D-08 dense-but-calm visual density.

---

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 (regular) | 1.5 |
| Label | 12px | 400 (regular) | 1.4 |
| Heading | 20px | 600 (semibold) | 1.3 |
| Display | 28px | 600 (semibold) | 1.2 |

**Source:** Desktop-optimized sizes. D-08 dense-but-calm → smaller than editorial, readable for numbers/tables. Weights limited to 2 values: 400 (regular) and 600 (semibold).

---

## Visual Hierarchy

**Focal point (primary invoice screen):** Invoice form heading (20px semibold) at top of left panel. First visual anchor when user enters Rechnung view. Draws eye before line-item cards or tax rail.

**Source:** D-14 split layout (form left, tax right). Heading establishes context before data entry.

---

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | hsl(222 47% 11%) | App background, main surfaces |
| Secondary (30%) | hsl(217 33% 17%) | Cards, sidebar, input backgrounds |
| Accent (10%) | hsl(217 91% 60%) | CTA buttons, active nav items, primary actions |
| Destructive | hsl(0 84% 60%) | Delete actions, error states |

Accent reserved for:
- Primary CTA buttons („Neue Rechnung", „Speichern")
- Active sidebar navigation item
- „+ Position" add line-item control
- Link text in empty states

**Source:** Dark-first theme (D-09). HSL values from shadcn default dark preset as baseline, will be refined during shadcn init.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Neue Rechnung |
| Empty state heading | Noch keine Rechnung erstellt |
| Empty state body | Erstellen Sie Ihre erste Rechnung und sehen Sie sofort die Steuerberechnung. Der komplette Ablauf – vom Entwurf bis zum fertigen PDF – dauert unter 2 Minuten. |
| Error state | Ein Fehler ist aufgetreten. Bitte versuchen Sie es erneut oder kontaktieren Sie den Support. |
| Destructive confirmation | Position löschen: Diese Position wird unwiderruflich entfernt. |

Additional copy elements:

| Element | Copy |
|---------|------|
| Sidebar nav items | Rechnung · Entities · Kunden · Tax · PDF |
| Add line item | + Position |
| Invoice form labels | Rechnungsnummer · Datum · Fällig · Bezeichnung · Menge · Einzelpreis · Netto |
| Tax rail heading | Live Steuerberechnung |
| PDF peek label | Vorschau |
| Disabled create hint | Wird in Phase 3 aktiviert |

**Source:** German UI per PRD. Invoice → tax → PDF loop language. D-24 empty state pattern (marketing copy). D-20 add control. D-31 disabled mock hint.
