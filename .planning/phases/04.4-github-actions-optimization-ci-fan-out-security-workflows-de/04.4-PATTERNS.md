**Aggregator pattern** (lines 312–338) — keep job id `ci`. Update `needs` + `check()` names in the **same commit** as the split (`lint`/`desktop-test`/`backend-unit`/`backend-e2e` → `desktop-web`/`desktop-rust`/`backend-test`; keep `squawk`).

```yaml
ci:
  timeout-minutes: 5
  needs: [changes, lint, desktop-test, backend-unit, backend-e2e, squawk]
  if: always()
  runs-on: ubuntu-latest
  steps:
    - name: Check job results
      run: |
        check() {
          local name="$1"
          local result="$2"
          if [ "$result" = "failure" ] || [ "$result" = "cancelled" ]; then
            echo "$name: $result"
            exit 1
          fi
        }
        check changes "${{ needs.changes.result }}"
        check lint "${{ needs.lint.result }}"
        check desktop-test "${{ needs.desktop-test.result }}"
        check backend-unit "${{ needs.backend-unit.result }}"
        check backend-e2e "${{ needs.backend-e2e.result }}"
        check squawk "${{ needs.squawk.result }}"
```

Skipped children are OK (GitHub reports skipped as Success). `failure`/`cancelled` fail the aggregator.
