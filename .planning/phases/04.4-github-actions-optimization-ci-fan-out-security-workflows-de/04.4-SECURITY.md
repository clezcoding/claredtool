# Phase 04.4 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| GitHub Actions runner → repo | CI clone of public repo | Workflow YAML, lockfiles, source |
| GitHub Actions → GHCR | Image push (backend-image) | Image layers; SHA tags only |
| GitHub Actions → Coolify | Deploy after image push | `COOLIFY_TOKEN` via env wrap; no JSON echo |
| GitHub Actions → FaynoSync | Staging updater upload | Signed bundles; staging host only in UAT |
| PR fork → workflows | Untrusted PR content | Must not use `pull_request_target` / `workflow_run` |
| Step summary → GitHub UI | Job markdown | No secrets, no PR titles, no Coolify JSON |
