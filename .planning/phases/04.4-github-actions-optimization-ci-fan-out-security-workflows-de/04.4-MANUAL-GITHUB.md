# 04.4 — Manuelle GitHub-Schritte (D-06)

Cursor ändert Branch Protection, Environments und Secret Scanning **nicht** per API (D-06). Gründer führt die Schritte nach Merge dieses PRs aus. Kein Production-Dispatch und kein `v*`-Tag in Phase 04.4 (D-06, D-09, D-12, D-34).

## Nach Merge — Settings

1. **Required check `gitleaks` (D-09).** Branch Protection auf `main`: Statuscheck **genau** `gitleaks` hinzufügen (Job-Name, nicht Workflow-Dateiname). Kein Admin-Bypass. `ci` bleibt der einzige stabile Aggregator-Check. CodeQL und Zizmor **nicht** required — sie sind pfadselektiv und würden sonst als Pending den Merge blockieren (D-13).
2. **Secret Scanning + Push Protection (D-12).** Public repo: beides aktivieren. Ersetzt Gitleaks nicht. Gitleaks bleibt fail-closed Merge-Gate.
3. **`GITLEAKS_LICENSE` (A1).** Prüfen, ob `clezcoding` eine GitHub-Organisation ist. `gitleaks-action` braucht für Orgs eine Lizenz (Free Starter reicht). User-Account: Origin lief ohne Secret. Kein License-Wert in YAML erfinden.
4. **D-17 Staging-Desktop nach Merge (nicht in diesem PR).** `workflow_dispatch` Staging auf **beiden** Runnern: `windows-2022` und `macos-15`. Production-Dispatch und `v*`-Tag bleiben aus.

## Dependabot vs CI-Service-Images (D-36, Pitfall 6)

Dependabot **cannot bump** `jobs.*.services.*.image` in `.github/workflows/ci.yml`. Die Ecosystems `docker`, `docker-compose` und `github-actions` in `.github/dependabot.yml` bumpen weiterhin Dockerfiles, Compose und Action-SHAs — **das deckt GHA-Service-Images nicht**.

D-36-Ersatz: **quartalweise manuell re-pinnen** von `postgres:16-alpine` und `redis:7-alpine` (Index-Digest, lesbarer Tag im Kommentar). Versionen bleiben 16 und 7. Befehl:

```bash
docker buildx imagetools inspect postgres:16-alpine
docker buildx imagetools inspect redis:7-alpine
```

## Gitleaks SARIF (Pitfall 7)

Job-Fail ist das Merge-Gate. SARIF im Security-Tab ist Extra. Ein späteres Commit, das ein Secret entfernt, markiert den Alert oft „resolved“, obwohl die Historie den Leak noch enthält. Rotieren, nicht nur löschen.

## D-34 GitHub-Szenariotabelle — nur nach explizitem Push-OK

Nicht ausführen, bis der User **push OK** sagt. Dann (kein Production-Dispatch, kein `v*`):

| Szenario | Was prüfen |
|----------|------------|
| Docs-only PR | `changes` + Aggregator `ci`; Gitleaks; Labeler; kein CodeQL/Zizmor/Rust |
| Draft-PR | `changes` + `ci`; Gitleaks; Heavy-Jobs skip bis `ready_for_review` |
| `ready_for_review` JS/TS | Pfadselektive Desktop-Web/Backend-Jobs; CodeQL-Workflow startet nicht auf PRs. |
| Rust-only | desktop-rust plus Aggregator; CodeQL-Workflow startet nicht auf PRs; Rust-Analyse nur auf main-Push / Schedule / Dispatch; kein Backend. |
| Backend-only | `backend-test` (+ squawk); keine Desktop-Jobs |
| Workflow-YAML | Zizmor + Actionlint; `ci` self-check wenn `ci.yml` in `shared` |
| Docs-only `main` | `fkirc/skip-duplicate-actions`: Heavy-Jobs skip wenn derselbe Tree schon auf der PR gruen war; sonst `changes` + Aggregator + Gitleaks; kein signed desktop-build |

## Vorher/Nachher Fan-out (Brief Deliverable 3)

Ist-Stand (Stichprobe 30.08.–04.09.2026, 200 Runs): Shared-Dependency-Push auf `main` bis **17 Jobs**; Docs-only `main` **10 Jobs**; `ci` + `desktop-build` + `codeql` ≈ **90 %** Runner-Zeit.

Kernhebel: Desktop-Frequenz (kein signed Build auf `main`), Pfadfilter auf `main`, CodeQL-Sprach-Split. Rückrechnung ≈ **40 %** Runner-Stunden (5,55 / 13,81 h). Keine Monatsprognose.

| Szenario | Vorher (Ist) | Nachher (erwartet) |
|----------|--------------|-------------------|
| Docs-only PR | `ci` Heavy + oft CodeQL + Gitleaks + Labeler | `changes` + Aggregator `ci`, Gitleaks, Labeler; kein CodeQL/Zizmor/Rust |
| Draft-PR mit Code | volle Heavy-Jobs | `changes` + `ci` + Gitleaks; Heavy wartet auf `ready_for_review` |
| `ready_for_review` JS/TS | JS+Rust CodeQL-Matrix | Desktop-Web/Backend nach Pfad; kein CodeQL-Workflow auf PRs |
| Rust-only | oft volle `ci` + beide CodeQL-Sprachen | desktop-rust plus Aggregator; kein CodeQL-Workflow auf PRs; Rust-Analyse nur auf main-Push / Schedule / Dispatch; kein Frontend/Backend |
| Backend-only | Desktop-Jobs mit | `backend-test` (+ squawk); keine Desktop-Jobs |
| Workflow-YAML | CI oft unnötig voll | Actionlint+Zizmor; `ci` nur wenn `ci.yml`/`shared` |
| Docs-only `main` | 10 Jobs inkl. signed Desktop | skip-duplicate (preflight) wenn Tree = letzte PR; sonst `changes` + Aggregator + Gitleaks; **kein** signed `desktop-build` |
| Weekly CodeQL | beide Sprachen (wie Schedule) | Schedule/Dispatch: **JS/TS und Rust vollständig** |
