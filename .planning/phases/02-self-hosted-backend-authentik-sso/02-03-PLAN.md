## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Authentik HTML in login WebView → Tauri IPC | Hostile-or-XSS page must not reach keychain |
| Login WebView navigation | Open redirect / evil host |
| OS protocol handler clared:// | Foreign apps can invoke the scheme |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-10 | Elevation of privilege | login WebView XSS → IPC | high | mitigate | login.json core:default only; keychain commands not permitted |
| T-02-11 | Spoofing | WebView navigation to evil host | high | mitigate | on_navigation allowlist BACKEND_URL + AUTHENTIK_URL only |
| T-02-12 | Information disclosure | Session in WebView storage | high | mitigate | Token only via main-window keyring commands (D-27) |
| T-02-13 | Spoofing | clared:// from another app | medium | mitigate | Ticket 60s one-time GETDEL on Nest (02-02); stale tickets fail |
| T-02-14 | Denial of service | Windows second instance | medium | mitigate | single-instance plugin first + deep-link feature |
| T-02-15 | Tampering | Sync window builder | medium | mitigate | async open_login_window only (wry#583) |
</threat_model>
