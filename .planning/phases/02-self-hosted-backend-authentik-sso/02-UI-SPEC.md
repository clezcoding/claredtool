## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge inline padding |
| sm | 8px | Chip inner gap, banner inner gap, compact padding, sidebar `p-2` |
| md | 16px | Default element spacing, gate column `gap-4`, banner padding |
| lg | 24px | Section padding |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing, gate vertical inset |

Exceptions: Interactive controls (gate „Anmelden“, chip, banner „Anmelden“, menu „Abmelden“) use 44px (`min-h-11`) minimum hit target (not strictly 4-multiple). Do not enlarge Phase 1 nav rows to 44px.

**Source:** Phase 1 UI-SPEC 8-point scale. No new scale this phase.

**Radius:** `--radius` / `--radius-md` = 8px. Gate hero, CTAs, chip, banners, badge, dropdown all use `rounded-md` (8px). Do not introduce a new radius.

## Visual Hierarchy

**Signed-out (this phase focal point):** Full-screen dark gate. Blur-test order: Higgsfield hero, then Display title „Clared“, then the one-line muted body, then the single accent „Anmelden“ button. One primary action. No sidebar, no invoice mock, no shell chrome, no second CTA.

**Signed-in:** Inherit Phase 1 — invoice form heading (20px semibold) remains the primary invoice-screen anchor. Session chip is tertiary chrome in the sidebar footer; it must not compete with nav or the invoice heading (no accent fill on the chip, no avatar, no extra shadow).

**Login window:** Native OS titlebar is the only Clared chrome. Authentik owns the content area. No Clared marketing copy, no sidebar, no hero inside this window.

**Banners:** Sit above content, never above the sidebar. They are recovery chrome, not a second hero.

**Source:** CONTEXT.md D-15, D-19, D-33, D-36. Phase 1 Visual Hierarchy for signed-in screens. Phase 1 D-08 dense-but-calm (flat surfaces, Card shadow only on banners).

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | hsl(222 47% 11%) | App background, gate, login-window stage, silent-boot screen |
| Secondary (30%) | hsl(217 33% 17%) | Cards, sidebar, chip surface, banner surface, dropdown, `--card` / `--popover` |
| Accent (10%) | hsl(217 91% 60%) | Reserved list below — never chip, never role badge |
| Destructive | hsl(0 84% 60%) | 401 banner message text; Phase 1 delete/error text. Not used on „Abmelden“. |
| Foreground | hsl(210 40% 98%) | Gate title, chip name, primary copy |
| Muted foreground | hsl(215 20% 65%) | Gate body, cancel banner message, Rolle label |
| Ring | hsl(217 91% 60%) | `focus-visible` ring only (`--ring`) |

Accent reserved for:
- Gate primary CTA „Anmelden“
- 401 banner button „Anmelden“
- Cancel/timeout banner button „Anmelden“
- Active sidebar navigation item (Phase 1 inherit)
- Phase 1 CTAs still on signed-in screens („Neue Rechnung“, „+ Position“, empty-state links)

Do **not** put accent on: session chip, `primaryRole` badge, login-window chrome, Authentik WebView, „Abmelden“.

**Dark-only:** `:root` and `.dark` share the same HSL in live CSS. No theme toggle. No light gate.

**Focus:** Gate CTA, banner „Anmelden“, chip trigger, and „Abmelden“ use `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-2 focus-visible:ring-offset-background`. Keyboard path is D-39; ring is the visible affordance (color is not the only signal).

**Source:** Live CSS variables in `apps/desktop/src/styles/globals.css` (same HSL as Phase 1 UI-SPEC). CONTEXT.md D-09 carry-forward (dark-first).

## Surfaces (this phase)

### Windows

| Window | Label | Size | Decorations | Title |
|--------|-------|------|-------------|-------|
| Main (existing) | `main` | 1280×800 default, resizable | native (`decorations: true`, Phase 1 D-07) | Clared |
| Login (new) | `login` (must differ from `main`) | 480×640 default **and** min | native | Anmelden |

Login is a **second Tauri WebView**, not a hash-router route, not a modal inside `main`. If `login` already exists, focus it — do not spawn a second login window. Navigation allowlist is `BACKEND_URL` + `AUTHENTIK_URL` (behavior, not a visual token).

### Silent boot

When a keychain token exists **or** the process launched from a still-valid `clared://auth?ticket=` (D-18), show a full-viewport dominant surface with centered existing `Spinner` (16×16) and the spinner’s `sr-only` „Wird geladen“. No gate flash, no sidebar, no invoice.

| `/me` or ticket outcome | UI |
|-------------------------|----|
| 200 | `AppShell` on the filled sample invoice (Phase 1 D-22). Chip populated from `/me`. |
| 401 | Gate (no banner unless the user just cancelled). |
| Network / 5xx / timeout | Phase 1 `ErrorState` on the same dominant surface (no shell, no gate, no login window). „Erneut versuchen“ re-calls `/me` or re-redeems. |
| Missing ticket / no `clared://` (normal cold start) | Gate only. No banner. |
| Ticket expired / invalid after `clared://`, or cancel / window close / 60s timeout | Gate + cancel banner „Anmeldung abgebrochen“. |

`prefers-reduced-motion: reduce`: spinner is a static 16×16 ring (no `animate-spin`). No other motion on boot or gate (hero is a static PNG).

### Signed-out gate

- Full viewport, `bg-background`, no `AppShell` sidebar. `html lang="de"` stays.
- Centered column `max-w-xl` (same slot as invoice empty state), `gap-4` (16px), vertical padding `3xl` (64px).
- Hero: `apps/desktop/public/login-gate-hero.png`, `w-full max-w-xl rounded-md`, `alt=""`. Do **not** reuse `/empty-state-hero.png`.
- Title: semantic `h1`, Display 28px / 600 / 1.2 — „Clared“.
- Body: 14px / 400 / 1.5, `text-muted-foreground`, wraps — „Anmelden, um Rechnungen zu stellen.“
- CTA: `@clared/ui` `Button`, accent/`bg-primary`, `min-h-11 font-semibold`, autofocus. Enter activates it. One control — no secondary link.
- Paid SaaS: never show product screens unsigned. No OSS/free/self-host language.
- After **Abmelden** succeeds: this gate, not an unsigned `AppShell`.

### Login window (extra Tauri window)

| Property | Value |
|----------|-------|
| Window label | `login` (must differ from `main`) |
| Size | 480×640 default |
| Min size | 480×640 |
| Resizable | true (Authentik MFA may need height) |
| Decorations | native OS titlebar (Phase 1 D-07) |
| Title | Anmelden |
| Sidebar | none |
| Theme | dark stage `hsl(222 47% 11%)` until Authentik paints |
| Content | Authentik / backend `/auth/login` WebView only |

While the WebView is navigating: centered `Spinner` on the dark stage. Do not skin Authentik. Authentik owns in-WebView scroll. Closing the window or ticket timeout (60s) is cancel — see banners. No auto-retry loop. No infinite spinner: native close is always available.

Logout (D-21): destroy this-device session, then open this same `login` window for Authentik `end_session`; after that flow, `main` shows the gate.

### Signed-in session chip

- Left sidebar stays `w-48` (`192px`) from Phase 1. Five Phase 1 nav items unchanged. Chip sits in a footer with `mt-auto`, padding `sm` (8px) matching nav `p-2`.
- Chip is a full-width `DropdownMenuTrigger asChild` wrapping `@clared/ui` `Button` with the chip className table above. Min-height 44px. Accessible name = display name. `aria-haspopup="menu"`.
- Row: display name (Body 14px / 400, `truncate` + `title` = full string) then `primaryRole` badge. Gap `sm` (8px).
- Name source: `/me.name`. If empty/whitespace, fall back to `/me.email`. Never show `sub`, never show `groups[]`, never show `permissions[]`.
- Badge: shadcn official `Badge` `variant="secondary"` (muted/secondary surface — **not** `default`, which is accent). Label 12px / 400. One badge = `primaryRole` only.

German badge labels (locked):

| `primaryRole` | Badge |
|---------------|-------|
| platform | Plattform |
| owner | Inhaber |
| admin | Admin |
| accountant | Buchhaltung |
| tax | Steuer |
| clerk | Sachbearbeitung |
| auditor | Prüfung |
| viewer | Ansicht |

Unknown `primaryRole`: show the raw value, still Label 12px, still `variant="secondary"`.

### Mini-menu

shadcn official radix `dropdown-menu` (`DropdownMenu` + `DropdownMenuContent side="top" align="start"`). Open on click / Enter / Space. Place above the chip. Escape closes. Arrow keys move to „Abmelden“. Keyboard must reach chip and „Abmelden“ (D-39). No global login shortcut. No `DropdownMenuShortcut`. Menu width matches the chip (sidebar inner width).

Menu contents, in order:
1. Read-only `DropdownMenuLabel`: `Rolle: {badge German label}` — not a button, not accent, Label 12px / 400 / `text-muted-foreground`.
2. `DropdownMenuSeparator`.
3. `DropdownMenuItem` „Abmelden“ — default variant, not `destructive`. Immediate: destroy this-device session + open login window for Authentik `end_session`. No confirmation dialog. No „Überall abmelden“.

Forbidden in this menu: profile, billing, settings, email, groups list, permissions list, avatar, theme toggle.

### Banners

Reuse `Card` + primary `@clared/ui` `Button`. Sticky top of the **main** pane when `AppShell` is visible; top of the gate column when signed out. Padding `md` (16px), gap `sm` (8px). Copy wraps. Never overlay the sidebar. `role="alert"` on 401; `role="status"` on cancel. Do not use toasts this phase.

| Trigger | Message (14px) | Button | Color |
|---------|----------------|--------|-------|
| HTTP 401 / 24h absolute expiry | Sitzung abgelaufen. Bitte erneut anmelden. | Anmelden | message `text-destructive`; button accent |
| Login cancel, window close, or ticket timeout | Anmeldung abgebrochen | Anmelden | message `text-muted-foreground`; button accent |
| Network / non-auth failure | Phase 1 `ErrorState` copy | Erneut versuchen | existing `ErrorState` — **not** the login window |

401: shell stays; last request retries after a successful login (behavior, not extra chrome). Network error: Phase 1 `ErrorState` + retry; do not open the login window. Never collapse a failed `/me` into the invoice empty state or the login gate’s marketing empty.
