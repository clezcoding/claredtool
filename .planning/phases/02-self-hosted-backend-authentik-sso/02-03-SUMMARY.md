## Accomplishments

- Main can store/read/delete an opaque Bearer in the OS keychain (`com.clared.app` / `session`) via three Tauri commands
- Extra window `login` opens asynchronously (480×640, title Anmelden, decorations true) from `open_login_window`
- Login WebView is navigation-only: no keychain IPC, no `os:allow-hostname`; CSP + `on_navigation` allowlist for `BACKEND_URL` and `AUTHENTIK_URL`
- `clared://` extracts `ticket`, emits `ticket-received` to main, closes login, returns false
- `tauri-plugin-single-instance` registers first (deep-link feature); scheme `clared` in `tauri.conf.json`; bundle id stays `com.clared.app`

## Decisions Made

- **AppManifest ACL in `build.rs`:** Tauri allows all app commands from every window unless `AppManifest::commands` is set. Listing keychain + `open_login_window` is what makes `login.json` actually deny keychain (T-02-10).
- **CSP via `initialization_script`:** `WebviewWindowBuilder` has `on_navigation` but no per-window CSP setter; A3 meta inject plus allowlist.
- **`login-init.html` as `include_str` data URL:** file lives in `src-tauri/` as specified; Vite `public/` would be a second copy.
