## Common Pitfalls

### Pitfall 1: R-01 width measured wrong rail
**What goes wrong:** Normalize to 360px “sidebar” from backlog.
**Why it happens:** Backlog said `02=360px` but that is the **tax aside**, not nav.
**How to avoid:** Use `w-[260px]` from `02-rechnung-light` nav; close R-01 as superseded (D-19).
**Warning signs:** Tax rail and nav share same width constant.

### Pitfall 2: stitch-build validate fails on Stitch hex
**What goes wrong:** Wave gate red despite correct pixels.
**Why it happens:** `validate.js` forbids `#[hex]` in `className`.
**How to avoid:** After 1:1 port, promote hex into `globals.css` / `@theme` then use semantic classes before running validate (D-06).
**Warning signs:** `STYLE: Found N hardcoded hex codes`.

### Pitfall 3: Byte-equal PNG file hashes
**What goes wrong:** Identical pixels, different PNG encoding → CI fail.
**Why it happens:** “Byte-equal PNGs” misread as file hash.
**How to avoid:** Operational definition: **same dimensions + `pixelmatch(..., { threshold: 0 }) === 0`**. Optional secondary: identical buffers only if same encoder path.
**Warning signs:** Diffs=0 but `Buffer.compare` ≠ 0.

### Pitfall 4: Viewport / DPR mismatch
**What goes wrong:** 1280×800 window vs 1536×1024 approved mockups.
**Why it happens:** Default Tauri size ≠ mockup size; Retina 2x.
**How to avoid:** Pin Mac host, `devicePixelRatio`, and capture size to **1536×1024** content (match `mockups/approved/02-rechnung-light.png`) `[VERIFIED: sips pixelWidth/Height on approved PNG]`. Prefer Tauri MCP `webview_screenshot` `format: "png"` (no OS chrome).
**Warning signs:** Systematic scale/letterbox diffs.

### Pitfall 5: Material ligatures leak into a11y names
**What goes wrong:** Screen readers announce `receipt_long`.
**Why it happens:** Ligature text nodes without `aria-hidden` (backlog R-13 / mf10).
**How to avoid:** D-46 — decorative `aria-hidden`; meaningful icons use i18n `aria-label` and empty accessible name on glyph.
**Warning signs:** axe/a11y warnings on nav icons.

### Pitfall 6: Dual icon systems visual clash
**What goes wrong:** Lucide stroke icons next to filled Material glyphs in same chrome.
**Why it happens:** Shell partially converted.
**How to avoid:** Shell wave replaces nav icons with Material (file touched → D-47 allows migrate).

### Pitfall 7: F-gap “done” without pixel proof
**What goes wrong:** Features exist but fail auto-diff.
**Why it happens:** Implementing chrome without harness gate.
**How to avoid:** Per-route QA note + harness (D-22); human UAT once at end (D-23).

### pixelmatch gate (D-20/D-21)
```js
// Source: Context7 /mapbox/pixelmatch — threshold 0 = exact match
import fs from "node:fs";
import { PNG } from "pngjs";
import pixelmatch from "pixelmatch";

const expected = PNG.sync.read(fs.readFileSync(goldenPath));
const actual = PNG.sync.read(fs.readFileSync(actualPath));
if (expected.width !== actual.width || expected.height !== actual.height) {
  throw new Error("dimension mismatch");
}
const diff = new PNG({ width: expected.width, height: expected.height });
const n = pixelmatch(
  expected.data,
  actual.data,
  diff.data,
  expected.width,
  expected.height,
  { threshold: 0 },
);
if (n !== 0) fs.writeFileSync(diffPath, PNG.sync.write(diff));
process.exit(n === 0 ? 0 : 1);
```
