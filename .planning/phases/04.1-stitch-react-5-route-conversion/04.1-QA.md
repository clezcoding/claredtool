## Host

- **OS:** macOS arm64 (developer machine). Record `sw_vers` in the per-route QA row.

## Viewport

Force content size **1536×1024** before capture so goldens match `mockups/approved/`.

## Capture

Prefer Tauri MCP `webview_screenshot` with `format: "png"` (window `main`). Do not OS-screencapture the full native chrome unless cropping the titlebar first — titlebar breaks D-21.

## Theme

Capture **light and dark** where approved pairs exist (D-25). Drive theme via existing `applyTheme('light' | 'dark')`. Disable motion (`prefers-reduced-motion` or `--dur: 0`) so animations cannot flake bytes.

## Diff

`node apps/desktop/scripts/pixel-diff.mjs <expected.png> <actual.png> [diff.png]`

- Equal dimensions + `pixelmatch` **threshold 0** → exit 0 (A1 operational byte-equal).
- Dimension mismatch → non-zero (no pixel hash).
- Pixel mismatch → non-zero + writes a diff PNG.

Self-check: `node apps/desktop/scripts/pixel-diff.mjs --self-test equal,dimension-different,pixel-different`
