# Phase 04.1 — UI Design Contract

> Visual and interaction contract for the Stitch→React 5-route conversion (Rechnung · Entities · Kunden · Tax · PDF). Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Conversion law (D-05/D-06):** Stitch HTML/PNG is the visual SSOT. Take Stitch classes / hex / spacing **1:1** into TSX. When a Stitch value diverges from the Crafted Minimal `globals.css` CSS vars below, **Stitch wins**; the CSS vars are synced afterward to match. This contract records the *current* Crafted Minimal baseline plus the measured Stitch values that override it.

## Spacing Scale

Crafted Minimal baseline (multiples of 4). Stitch classes taken 1:1 (D-05) resolve to these; any Stitch spacing that diverges wins and is synced back.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, chip inset |
| sm | 8px | Compact element spacing, list row gaps |
| md | 16px | Default element spacing, card padding |
| lg | 24px | Section padding, form group spacing |
| xl | 32px | Layout gaps, panel padding |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Radius tokens (from `globals.css`): `--radius-sm 4px`, `--radius-md 8px` (default `--radius`), `--radius-lg 12px`.

**Exceptions / measured Stitch layout constants (SSOT — do not remap):**
- **AppShell sidebar (left `<nav>`) width = `260px`** — measured from `02-rechnung-light` (D-18). Normalize all five routes to this single width. Backlog R-01's "02=360px" measured the *right tax rail* `<aside>` (`w-[360px]`), not the nav; **R-01 is closed as superseded** (D-19) — record PASS in `STITCH-APPROVAL-BACKLOG.md`.
- Shell top bar height: `72px` (rail is `top-[72px] h-[calc(100vh-72px)]`).
- Rechnung right tax rail (`<aside>`) width: `360px` (route-local, not the shell rail).
- Content max width: `1000px` (`max-w-[1000px]` on Rechnung canvas).
- Motion: duration `--dur 180ms`, ease `--ease-out cubic-bezier(0.22, 1, 0.36, 1)`; `prefers-reduced-motion` collapses transitions to 1ms (already in `globals.css`). Keep <300ms.

## Typography

Canonical scale (declared roles). Base body is 14px/1.5/400 (from `globals.css body`). Serif reserved for wordmark + money totals.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 (normal) | 1.5 |
| Label / caption | 11–13px | 500 (medium) | 1.4 |
| Heading | 18–20px | 500–600 (medium/semibold) | 1.3 |
| Display / money total | 28–40px | 600 semibold (serif for totals) | 1.15 |

Weights in use across Stitch surfaces: **`font-medium` (500)** and **`font-semibold` (600)** only (no bold/black). Body default 400. → 2 non-body weights, per contract.

**Stitch 1:1 exception (D-05):** Stitch screens carry heterogeneous inline sizes — measured union across the 5 routes: `10, 11, 12, 13, 14, 15, 16, 18, 20, 22, 24, 28, 32, 40px` plus Tailwind `text-xs/sm/base/lg/2xl` on 06-tax-engine. These are taken verbatim into TSX; the four roles above are the *semantic buckets* the checker validates against, not a mandate to collapse Stitch pixel values. Executor keeps Stitch values; planner maps each to the nearest role for consistency review.

## Color

Crafted Minimal 60/30/10 (light). Stitch hex taken 1:1 where it diverges (D-06) — measured Stitch neighbors noted.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#F7F7F5` Pale Oatmeal (`--background`; sidebar `bg-paper-oatmeal` ≈ `#F9F9F7`) | App background, sidebar/nav surface |
| Secondary (30%) | `#FFFFFF` Pure White (`--card`; `bg-paper-white`) | Cards, right tax rail, panels, PDF paper |
| Accent (10%) | `#A8BFA3` Sage (`--primary` / `--accent` / `--ring` / `--nav-active-bar`; Stitch neighbors `#a7d0b2`,`#a8d1b3`,`#c3edcd`) | See reserved-for list |
| Destructive | `#C9A227` Amber (`--destructive`; Stitch error `#BA1A1A`/`#FFDAD6` on native Stitch error chips) | Destructive / error emphasis only |

Foreground: `#111110` Deep Charcoal (`--foreground`). Muted text: `#8A8A8A` (`--stone`/`--muted-foreground`). Border/hairline: `#E8E8E4` light / `#2A2A28` dark.

**Dark theme:** single component tree + `dark:` variants, OS-follow (D-07). Dark surfaces: `--background #0F0F0F`, `--card #1A1A1A`, hairline `#2A2A28`. `.money-display` gets sage glow; `.bg-card` gets depth shadow (in `globals.css`).

**Accent (Sage) reserved for:**
- Nav active-state indicator bar (`--nav-active-bar`, NavLink `isActive` — D-17)
- Primary CTA send button (`--cta-send`, e.g. Rechnung *Senden*)
- Focus ring (`--ring`)
- Selected list/panel row highlight (Entities/Kunden shared List+Panel)
- Sage "press" affordance on primary buttons

Never apply Sage to all interactive elements, body links, or decorative fills.

**PDF paper guard (D-09 carryover):** `PdfPaper` keeps inline `#fff`/`#111`; dark tokens must not invert invoice paper content.
