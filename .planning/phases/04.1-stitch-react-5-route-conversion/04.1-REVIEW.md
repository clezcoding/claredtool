# Phase 04.1: Code Review Report

**Reviewed:** 2026-08-28T00:07:00Z

## Summary

Phase 04.1 delivers the Stitch→React five-route conversion with shared AppShell, i18n/Material scaffold, Dialog overlays, live `apiFetch`/tax hooks on Rechnung, and List+Panel for Entities/Kunden. Structure matches D-11/D-13 (five nav items) and BRAND-01 token patterns. Tests and `stitch:validate` gates are in place.

One **critical** correctness gap: the Rechnung tax rail can show a prior customer's tax decision after entity/customer changes or a failed re-evaluation — violating TAX-01 live-preview trust. Seven warnings cover panel-close behavior, signed-in persona duplication, i18n gaps, and tooling portability. Pixel threshold-0 FAIL is a known Phase 06 residual, not a source-code defect.

## Critical Issues

### CR-01: Stale tax rail after entity/customer change or evaluate failure

**File:** `apps/desktop/src/routes/rechnung.tsx:495-506`, `806-809`, `417-419`
**Issue:** `railTax` is only cleared in `startNewDraft`, empty-load, and invoice-picker paths. `handleEntityChange` clears `customerId` but not `railTax`; customer `Select` `onValueChange` only sets `customerId`. On evaluate failure, `setTaxEvaluateError` runs but `railTax` keeps the last-good decision. User can see wrong VAT %, legal reference, and totals for the current entity/customer until a successful `/api/tax/evaluate` — or indefinitely after failure.
**Fix:**
```typescript
function clearRailTax() {
  setRailTax(null);
  setTaxEvaluateError(null);
}

function handleEntityChange(nextEntityId: string) {
  clearRailTax();
  // ...existing body
}

// customer Select onValueChange:
onValueChange={(value) => {
  clearRailTax();
  setCustomerId(value);
  if (canWrite) setAutosaveStatus("saving");
}}

// evaluateDraft failure branch:
setTaxEvaluateError("evaluate_failed");
setRailTax(null);
setTaxLiveState(lastGoodTaxRef.current, "evaluate_failed");
```

## Warnings

### WR-01: Detail panel close immediately reopens first row

**File:** `apps/desktop/src/routes/entities.tsx:108-114`, `apps/desktop/src/routes/kunden.tsx:127-133`
**Issue:** `useEffect` treats `selectedId == null` as “auto-open first row” (F-08). `closePanel()` sets `selectedId` to `null`, so the effect re-selects row 0 on the next tick. Close button in `registry-list-panel.tsx:465` is non-functional.
**Fix:** Track an explicit `hasAutoOpened` ref, or gate the effect with `panelMode !== "none"` so user-initiated close is respected.

### WR-02: Signed-in shell still renders R-02 persona block

**File:** `apps/desktop/src/components/app-shell.tsx:116-138`
**Issue:** When `me` is set, `SessionChip` shows name/role, but the block below still renders `personaEmail` (duplicate) and `personaCompany` (always `t("persona.company")` fallback, not session data).
**Fix:** Wrap lines 117–139 in `{me ? null : (…)}` or render company from session when available.

### WR-03: TaxRail drops evaluateError detail

**File:** `apps/desktop/src/components/tax-rail.tsx:113-114`
**Issue:** `evaluateError` prop is accepted but never rendered; only generic `t("taxRail.evaluateError")` shows. Callers cannot surface API-specific failure context.
**Fix:** `{evaluateError ? <p>…{evaluateError === "evaluate_failed" ? t("taxRail.evaluateError") : evaluateError}</p> : null}`

### WR-04: ErrorState body not i18n-backed

**File:** `apps/desktop/src/components/error-state.tsx:11-14`
**Issue:** Title uses `t("error.retry.title")` but the paragraph is hardcoded German. Breaks D-41 EN bundle and UI-01 copy contract.
**Fix:** Add `error.retry.body` to `de.json`/`en.json` and use `t("error.retry.body")`.

### WR-05: Duplicate tax-percent logic in Rechnung

**File:** `apps/desktop/src/routes/rechnung.tsx:613-614`
**Issue:** Inline `rate <= 1 ? Math.round(rate * 100) : Math.round(rate)` duplicates `taxPercent` in `apps/desktop/src/lib/money.ts` already used by `TaxRail`. Drift risk if engine format handling changes.
**Fix:** `import { taxPercent } from "../lib/money"` and pass `taxPercent(rate)` to `LineItemCard`.

### WR-06: stitch-validate hardcodes developer machine path

**File:** `apps/desktop/scripts/stitch-validate.mjs:6-7`
**Issue:** `VALIDATE` is an absolute path under `/Users/puzzless/.cursor/plugins/cache/…`. Fails on other machines/CI unless cache layout matches.
**Fix:** Resolve via `pnpm root`, env var, or package-relative lookup with documented install step (as 04.1-02 SUMMARY notes for `@swc/core`).

### WR-07: Rechnung modal copy bypasses i18n

**File:** `apps/desktop/src/routes/rechnung.tsx:1119-1143` (and send/delete dialog blocks)
**Issue:** Create/send/delete modal titles and labels are hardcoded German while shell uses `t()`. D-41 partial coverage.
**Fix:** Move strings into `de.json`/`en.json` under `invoice.modals.*`.
