### Stitch pixel-role consistency review (config, batch)

**Analogs:** `.stitch/designs/02-rechnung-light.html` lines 85–113; `.stitch/designs/04-entities-light.html` lines 109–128; `04.1-UI-SPEC.md` lines 35–73.

For every Stitch source, record each distinct typography and spacing pixel value before token sync. Required row shape: `source path:line`, `property`, `original px`, `nearest semantic role`, `final TSX/CSS location`. Never rewrite original value to role default.

**Typography seed map:** `10px`, `11px`, `12px`, `13px` = caption/meta; `14px`, `15px`, `16px` = body/label; `18px`, `20px`, `22px`, `24px` = heading/subheading; `28px`, `32px`, `40px`, `44px`, `60px` = display/money. Role label does not collapse values.

**Spacing seed map:** `4px` = xs; `8px` = sm; `16px` = md; `24px` = lg; `32px` = xl; `48px` = 2xl; `64px` = 3xl. Divergent values remain exact and get nearest-role annotation.

**Hard exclusion:** `260px`, `72px`, `360px`, `1000px` never appear in spacing-role rows. Classify as `layout.sidebar`, `layout.topbar`, `layout.rechnungTaxRail`, `layout.rechnungContentMax`.
